# 功能說明（給 AI agent 讀）

這份寫給幫使用者裝好寶可夢牧場的 AI agent（Claude Code、Codex…）。使用者問「黃色泡泡是什麼」「為什麼多了一隻」「怎麼拿掉」這類問題時，照這份回答。安裝步驟在 [install.md](install.md)，這份只講裝好之後怎麼用、看到的東西是什麼意思。

回答時用使用者的語言，講使用者看得到的東西（泡泡、名牌、選單），不用講程式細節。

## 一句話說明

桌面上一座 3D 小島，**每個 Claude Code／Codex session 認養一隻第一代寶可夢**。寵物在島上自由走動，頭上的泡泡顯示那個 session 的 agent 正在做什麼；需要使用者處理（確認、出錯、做完）時，泡泡變色，還會有音效和動作。同時開很多個 session 時，不用一個個切回去看。

你（正在讀這份的 agent）所在的 session 也有一隻。

## 泡泡顏色

| 泡泡 | 意思 | 使用者要做什麼 | 動作與聲音 | 什麼時候消失 |
|------|------|------|------|------|
| 白色「思考中…」 | agent 收到提示、正在想 | 不用 | 照常走動 | 下一個事件 |
| 白色「動詞：說明」 | agent 正在用工具，例如「跑指令：執行型別檢查」「寫程式：login.ts」「翻檔案：README.md」「查資料：github.com」「派小幫手：檢查連結」 | 不用 | 照常走動 | 下一個事件；3 分鐘都沒有新事件也會消失（長指令跑很久時） |
| 黃色「需要你確認」 | agent 在等使用者：要權限、問問題、計畫等批准。子代理要權限時是「小幫手需要你確認」 | **回到那個 session 處理** | 停下來面向畫面、一直跳，叮咚聲 | 使用者處理完；30 分鐘都沒處理也會消失 |
| 紅色「○○失敗了」 | 工具執行失敗，例如「跑指令失敗了」。使用者按 Esc 中斷不算失敗 | 看一下那個 session，通常 agent 會自己處理 | 播攻擊動作，低音提示聲 | 下一個事件；3 分鐘都沒有新事件也會消失 |
| 淡紫「整理記憶中…」 | 對話太長，agent 正在壓縮對話 | 不用，等它做完 | 照常走動 | 壓縮完 |
| 綠色「做完了！」 | 這一輪做完了 | 回去看結果 | 播開心動作，上揚的三個音 | 約 6 秒 |
| 沒有泡泡 | 閒著 | — | 自己逛 | — |
| 頭上飄 Zzz | 5 分鐘沒有任何動靜，躺下睡覺 | 不用 | 睡覺動作 | 下一個事件就醒來，先伸懶腰 |

- 動詞的對照：翻檔案（讀檔、搜尋）、寫程式（改檔、寫檔）、跑指令、查資料（抓網頁、搜尋網路）、派小幫手（子代理）、用外掛工具（MCP 工具）。
- 151 隻裡有 114 隻有睡覺動作；其他 37 隻沒有睡覺動作，5 分鐘沒動靜也不會躺下。

## 名牌

點一下寵物（或滑鼠移過去）會顯示名牌：**寶可夢名字 · session 名稱**。

- Claude Code：session 名稱是桌面版側欄上的標題；終端機開的 session 要改過名或自動取過名才有標題，沒有就顯示專案資料夾的名字。
- Codex：前面多「Codex ·」。名稱是安裝時用 `--title` 指定的，沒指定就是專案資料夾的名字。
- session 結束後名牌後面會加「（下線）」。

使用者問「哪一隻是這個 session」：請他看名牌或選單裡的寵物清單，找這個 session 的標題或專案資料夾名稱。

## 寵物的一生

- **認養**：一個新 session 第一次有動靜（送出第一句話），就從島上還沒有的品種裡隨機挑一隻。151 隻都有人養了才會重複。
- **一個 session 一隻**：Claude Code 和 Codex 的 session 各自算。子代理（subagent）**不會**另外養一隻；子代理在做事時，主 session 的寵物不會睡著，子代理要權限時主 session 的寵物會變黃。
- **會留著**：重開 App、重開電腦，寵物都還在。session 結束後寵物**不會消失**，只是變成「下線」，之後去睡覺。
- **拿掉**：從選單「牧場上的寵物」找到那一隻 →「放生…」，確認後拿掉。「全部放生…」一次清空。放生後，如果那個 session 還開著，下一次有動靜會再認養一隻（可能是別的品種）。

## 寵物自己的日常

- 待機、走路、偶爾跑、偶爾開心一下，會繞開樹、石頭和別隻寵物。
- **各有地盤**：陸地的在地上，水系的在水裡游，兩棲的兩邊都去。
- **打架**：兩隻醒著的正面撞上，有機率打一場（互相攻擊幾下），輸的冒汗逃到另一頭。純粹好玩，跟 agent 的狀態無關。
- **大小**：依官方體型分級，卡比獸站在小拉達旁邊看得出差別。
- **摸一下**：在置頂小牧場模式點寵物，牠會開心一下並顯示名牌。

## 選單

所有設定都在一個選單裡：

- **macOS**：Dock 上的精靈球圖示按右鍵。
- **Windows**：系統匣（工作列右下角）的精靈球圖示，左鍵或右鍵都可以；圖示可能收在「^」裡面。

| 選單 | 用途 | 平台 |
|------|------|------|
| 牧場上的寵物 | 每一隻和牠的 session（● 在線、○ 下線），子選單「放生…」 | 都有 |
| 全部放生… | 確認後清空整座牧場 | 都有 |
| 置頂 | 小牧場要不要一直在最上層。取消後會被其他視窗蓋住，勾回來會拉到最前面（只在置頂小牧場模式出現） | 都有 |
| 置頂小牧場／桌布模式 | 切換兩種模式 | 只有 macOS |
| 桌布放在哪個螢幕 | 桌布模式要鋪在哪個螢幕 | 只有 macOS |
| 地圖 | 「隨機」（每次啟動抽一張）或固定某一張 | 都有 |
| 重新掃描模型、打開模型資料夾 | 增減模型之後用 | 都有 |
| 結束寶可夢牧場 | 關掉 App（macOS 用 Dock 本來就有的「結束」） | 只有 Windows |

## 兩種模式

- **置頂小牧場**（預設）：透明、無邊框的小視窗，在桌面右下角。游標在島上才接滑鼠，其他透明的地方點得到後面的視窗。按住地面拖曳可以搬動整座牧場，拖到別的螢幕會換成適合那個螢幕的大小，下次開在同一個地方。
- **桌布模式**（只有 macOS）：鋪滿整個螢幕，在所有視窗和桌面圖示底下，像動態桌布。收不到滑鼠，所以不能點寵物、不能拖曳；放生的確認框會出現在主螢幕。

| 地圖 | 樣子 |
|------|------|

| 中央河 | 一條微彎的河把島分成兩岸，上岸是營地與營火；陸地的寵物過不了河 |
| 雪地 | 小木屋、松林、雪屋、雪人、結了浮冰的湖，天上飄雪 |
| 日式賞櫻 | 池泉庭園：瀑布、太鼓橋與鳥居、枝垂櫻、會動的鹿威し，花瓣飄落 |
| 中央島 | 四面環海的沙島：一棵大椰子樹、一顆排球、沖上岸的包裹、半埋在沙裡的橡皮艇；水系繞著島游 |

## 隱私與安全

使用者常問「牠看得到我在做什麼嗎」。回答重點：

- **只在這台電腦**：hook 只送到 `127.0.0.1`（本機），不連網路、不送到任何伺服器。
- **泡泡上只會出現**：檔名（不含路徑）、agent 自己寫的指令說明、網域、子代理的任務說明、問題的短標題、skill 名稱。
- **不會出現、也不保存**：提示文字、指令本身、檔案內容、搜尋字串、agent 的回覆。這些在收到事件時就丟掉，不寫 log。
- **網頁冒充不了**：帶 `Origin` 標頭的請求（瀏覽器發的）一律拒絕。
- **不拖慢 agent**：hook 最多等 1 秒、一定成功結束；牧場沒開時連線馬上被拒，agent 照常工作。

## 存檔

| 平台 | 位置 |
|------|------|
| macOS | `~/Library/Application Support/Pokemon Ranch Pets/` |
| Windows | `%APPDATA%\Pokemon Ranch Pets\` |

- `ranch.json`：哪個 session 養了哪一隻。
- `settings.json`：模式、地圖、置頂、桌布螢幕。
- `window.json`：小牧場的位置。

🔴 App 開著時不要手改這些檔案：App 只在啟動時讀一次，之後會用記憶體裡的內容蓋回去。要拿掉寵物請用選單的「放生」。

## 使用者常問的問題

| 使用者問 | 怎麼回答、怎麼查 |
|------|------|
| 開了 session 但沒有寵物 | 要送出第一句話才會認養。還是沒有的話，照 [install.md 的常見問題](install.md#常見問題) 查 hooks 和 port。 |
| 為什麼多了好幾隻 | 每個 session 一隻，結束的 session 寵物也會留著（名牌有「（下線）」）。不要的用選單「放生」或「全部放生」。 |
| 子代理怎麼沒有自己的寵物 | 設計如此：子代理算在主 session 那一隻身上。 |
| 哪一隻是現在這個 session | 看名牌或選單的寵物清單，找這個 session 的標題或專案資料夾名稱。 |
| 寵物一直在睡 | 那個 session 5 分鐘沒有動靜，正常。有新動靜就會醒。 |
| 黃色泡泡一直不消失 | 那個 session 還有沒處理的確認（權限、問題、計畫）。回去處理就會消失；30 分鐘沒處理也會自己消失。 |
| 白色泡泡卡很久 | 通常是一個指令跑很久，中間沒有事件。3 分鐘都沒事件會自己消失。 |
| 換了地圖，寵物位置全變了 | 正常：換地圖會重新蓋場地，寵物重新找位置。 |
| 小牧場擋到視窗 | 選單取消「置頂」；macOS 也可以改用桌布模式。 |
| 想要牠在桌布上 | macOS 選單「桌布模式」；Windows 沒有桌布模式。 |
| 可以點寵物嗎 | 置頂小牧場模式可以（摸一下）；桌布模式收不到滑鼠。 |
| 想要指定某一隻寶可夢 | 目前不行，認養是隨機的。可以放生後讓它重新認養（還是隨機）。 |
| 想關掉音效 | App 沒有音效開關；音效是 App 自己合成的，跟著系統音量。 |
| 會不會拖慢 Claude／Codex | 不會：hook 最多等 1 秒、一定成功結束，牧場沒開時立刻略過。 |
| 寶可夢模型可以分享嗎 | 不行。模型屬於原權利方，只能在自己的電腦上用，不要放進 git 或傳給別人。 |

## 給 agent 的守則

- 🔴 改 `~/.claude/settings.json` 或 `~/.codex/hooks.json` 之前先問使用者。
- 🔴 不要自己關掉、重開或重新打包使用者正在用的 App。
- 🔴 不要對 `127.0.0.1:47821` 送測試事件：那是使用者真的牧場，送了就會認養一隻假寵物。要測試請照 [README 的開發一節](../README.md#開發) 換 port 和存檔目錄。
- 不要手改存檔（見上面「存檔」）。
